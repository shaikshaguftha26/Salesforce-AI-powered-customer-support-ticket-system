# Salesforce-AI-powered-customer-support-ticket-system


## 📌 Project Overview

The AI-Powered Customer Support Ticketing System is built on the Salesforce Platform to help organizations efficiently manage customer support requests. The system automates ticket creation, categorization, prioritization, assignment, and tracking, enabling support teams to resolve customer issues more effectively.

---

## 🚀 Features

- User Authentication
- Customer Ticket Creation
- AI-Based Ticket Categorization
- Automatic Priority Assignment
- Ticket Assignment to Support Agents
- Ticket Status Tracking
- Search and Filter Tickets
- Admin Dashboard
- Secure Data Management
- Case Resolution Workflow

## ⚙️ Project Workflow

1. User logs into Salesforce.
2. Customer creates a support ticket.
3. The system categorizes and prioritizes the ticket.
4. The ticket is assigned to the appropriate support agent.
5. Agents update the ticket status during resolution.
6. Administrators monitor ticket progress through dashboards and reports.
